# Tab multi-selection

Shift-click selects a range of visible tabs in a sidebar Space or a horizontal tab strip. Cmd-click toggles individual tabs; Cmd-Shift-click adds a range. Ordinary clicks return to normal tab activation. Multi-selection does not switch focus, and it remains separate from the active tab and search target.

Right-click a selected tab to group, split, move to an existing or new view, remove from a stack, or close the selection. Right-click an unselected tab to act on that tab alone. Grouping extracts exactly the selected tabs. Nested arrangement tabs retain all their members. Hidden, filtered, collapsed and closed-pin rows are not included in ranges; open pins participate.

Bulk drag is intentionally not provided: use the batch Move menu. Ordinary tab dragging remains available after a plain click.
